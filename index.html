How It Works

Direct Device-to-Device in 3 Steps

Zero internet servers in the middle. Your devices discover each other locally and stream files straight across your Wi-Fi hardware.

1

Pick Any File or App

Tap Send to pick photos, 4K videos, installed Android apps (automatically named AppName.apk), archives, or tap Any File for any extension.

2

What We Use

Built on Fast, Transparent Local Protocols

No cloud middlemen, no proprietary dongles, and no bloated SDKs — just native hardware networking in a modern interface.

Local HTTP / TCP Engine

Transport Layer

Every receiver runs an embedded local HTTP/TCP socket server on port 53318 that streams raw bytes in large chunks with live speed and batch progress telemetry.

UDP + mDNS / Android NSD

Zero-Delay Discovery

Pre-warmed UDP multicast/broadcast pulses paired with native mDNS/NSD detect nearby phones, Windows PCs, and Linux machines automatically.

Wi-Fi Direct & QR Handoff

Routerless P2P

When no shared router is available, Android's native Wi-Fi Direct (LocalOnlyHotspot / P2P) spins up a direct peer link with one-scan QR credentials.

Flutter + Native Kotlin & C++

Cross-Platform Stack

Compiled natively via Flutter with custom Kotlin platform channels on Android (MediaStore, installed APK export) and native desktop runners for Windows and Linux.

Zero Cloud, Zero Ads, Zero Tracking

Strict Local Privacy

SendSnap has no analytics SDKs, no ad networks, and no login servers. Your personal files travel only between devices in the room.

Modern UI & 4 Languages

UX & Accessibility

Crafted with a sleek minimalist UI with Light & Dark mode, Google Files-style Recents, Desktop Multi-File Finish Studio, and full EN/FR/AR (RTL)/ES support.

FAQ

Common Questions, Direct Answers

Do I need internet or mobile data to use SendSnap?

No. SendSnap runs strictly over your local Wi-Fi network, mobile hotspot, or Wi-Fi Direct. You can transfer gigabytes with zero internet access and zero SIM data usage.

Can I send installed apps and any file extension?

Yes. Tap Send and open the Apps tab to pick any installed Android app or .apk, open Archives for .zip/.rar/.7z/.exe, or tap Any File to browse every extension on your device.

Does SendSnap work between Android, Windows PC, and Linux?

Yes! Download the portable Windows 64-bit release (.zip or .rar) or the Linux packages (.AppImage, .deb, or .tar.gz) above — no installer required for AppImage or zip. You can drag files straight onto discovered devices or use the desktop interface to open or preview batches.

Are my files uploaded to any cloud server?

Never. Data streams directly from the sender's local socket to the receiver's local disk. Nothing is ever uploaded, logged, or tracked.

Where are received files saved?

All received files are saved cleanly in Downloads/SendSnap on Android, Windows, and Linux, and you can also view or manage them directly in the app's Recents carousel and Received Library.
