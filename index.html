How It Works

Three Steps. Zero Servers.

Pure peer-to-peer networking that works even when the internet is completely down.

1

Select Any Content

Pick photos, 4K videos, installed Android apps (auto-packaged as AppName.apk), archives, or any arbitrary file extension on your device.

2

Instant Radar Pair

Nearby devices appear on the local radar through UDP, mDNS, and BLE beacons. No router? Generate an instant QR code for routerless Wi-Fi Direct.

3

Lightning Stream

Bytes stream directly over a dedicated TCP socket into Downloads/SendSnap at up to 100 MB/s. Preview immediately with the built-in media viewer.

Core Features

Crafted Without Compromise

Every line of networking, UI, and packaging is built for speed, transparency, and user privacy.

Embedded Socket Engine

Custom streaming engine on port 53318 handling large buffer chunking with real-time transfer telemetry and resume support.

Bare-Hand Air Gestures

Computer-vision camera hand tracking: wave, grab, and push files across screens touchlessly on Android, Windows, and Linux.

Routerless Hotspot Sharing

On camping trips, planes, or off-grid: Android Wi-Fi Direct spins up an isolated hotspot paired with a single QR scan.

Desktop Integration

Windows & Linux desktop runners with drag-and-drop file queues, system tray dock, and auto-minimize background listening.

100% Private & Offline

No accounts, no analytics SDKs, zero cloud telemetry, and zero ads. Your personal data never travels beyond your room.

Multilingual & RTL Support

Localized in English, French, Arabic (with full right-to-left layout and BiDi file sanitization), and Spanish.
